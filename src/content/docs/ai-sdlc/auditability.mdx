On the [map](../overview/), the auditability rail runs alongside every stage. Each stage leaves a **record** that points back to the one before it, so you can start from any line of merged code and walk back to the goal, and to the decision, that justified it. Switch on **Audit trail** on the map and click a stage to see its record.

Here is the walk itself. A new member of your pair's project opens the About screen code and asks a fair question.

Why it matters:

- **Months later**, the answer to "why?" is in the records, not in someone's memory.
- **Agents.** The next agent session plans from the same records (section 3). A broken trail for people is a broken context for agents.
- **Regulated software.** Medical-device software standards, such as IEC 62304, expect requirements to be traceable to the design, the tests and the risk controls, and every third-party component (SOUP) to be recorded. With the intended purpose the client stated, the Mood Tracker is not a medical device. A different purpose sentence could change that (see [product development](../../product/purpose/)), and it handles health data either way, so the habit costs little.
- **Two different regulatory questions.** *Is the app a medical device?* depends on its intended purpose (the EU Medical Device Regulation, MDR). *Does the app contain AI?* is a separate question under the EU AI Act. Using a coding agent to build the app does not make the app an AI system; an AI feature inside it, such as a chatbot or a predictor, would.
- **AI-assisted work.** The trailers, the pull request and your agent log record which agent and model contributed, what it cost, and who reviewed it. In W6 you add these up for the whole semester.

```bash title="Following the trail with Git"
git log --oneline --grep="GOAL-1"                        # every commit for the goal
git log --format='%h %s%n  %(trailers:key=AI-assisted)'  # who assisted each commit
git blame lib/config.dart                                # which commit wrote each line
```

:::tip[Do this in your project]
